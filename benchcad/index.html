PROJ-001 · 2025–2026● IN USE

Shush / Subrosa — voice dictation, everywhere

Double-tap volume-down on Android or hold a hotkey on desktop, speak, and the text lands in whatever app has focus. Android app in Kotlin, desktop app in Electron, transcription via Voxtral on Supabase Edge Functions with optional Haiku 4.5 cleanup. Plus a fine-tuned Moonshine Tiny (27M params) for German so dictation can run fully on-device. Early-access users get 1,000 words per 3 hours, tracked and rate-limited.

kotlin · electron · react · typescript · supabase · voxtral · moonshine · kaggle
